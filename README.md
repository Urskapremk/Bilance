# Bilance

Bilanca stanja in izkaz poslovnega izida v vizualnem jeziku [Hnatura](https://hnatura.app): belo ozadje, mornarsko modra, zlata in serifni naslovi.

Prvi prikaz je **GRAFAM d.o.o.** za obdobje 1. 1. 2026–31. 8. 2026, sestavljen iz bruto bilance. Postavke sledijo poenotenemu obrazcu AJPES za gospodarske družbe. Zneski so v evrih, s centi, da se ujemajo s konti.

## Zagon

```bash
npm install
npm run dev
```

Preverjanje seštevkov:

```bash
npm test
```
